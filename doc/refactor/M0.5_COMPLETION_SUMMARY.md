### 3️⃣ 实现的生成方法

#### 结构体生成
- ✅ `GenVertexInputStruct()` — 从 VertexEntry 生成 VertexInput 结构
- ✅ `GenVSOutputStruct()` — 生成 VS→FS 插值结构
- ✅ `GenLightingOutputStruct()` — 生成光照输出结构

#### 布局与基础函数
- ✅ `GenLayoutDeclarations()` — 生成 UBO/SSBO/Texture 的 layout 声明
- ✅ `GenCoordinateTransformFunctions()` — 坐标变换辅助函数

#### 核心：辅助函数库生成
- ✅ `GenHelperFunctionLibrary()` — 总调度器，根据 shader_stage 生成不同函数集
- ✅ `GenGetLocalToWorld()` — 获取 L2W 矩阵函数
- ✅ `GenGetNormalMatrix()` — 获取法线变换矩阵
- ✅ `GenGetNormalFunction()` — 法线计算（VS 有参/无参两版、FS 返回插值）
- ✅ `GenGetPositionFunctions()` — 位置获取函数（VS 计算、FS 返回插值）
- ✅ `GenGetMaterialInstanceFunctions()` — 材质实例获取

#### 输出与整合
- ✅ `GenOutputCompositionCode()` — 根据 ShaderOutputMode 生成输出合成代码
- ✅ `GenLightingCode()` — 光照计算（M2-M3 详细实现的占位符）
- ✅ `GenPreamble()` — 版本 + permutation #define 生成

#### 主入口函数
- ✅ `ComposeVertexShader()` — 7 步组装完整 VS（前置→布局→结构体→变换→辅助→业务→main）
- ✅ `ComposeFragmentShader()` — FS 对应实现
- ✅ `ComposeGeometryShader()` — GS 占位符（M2-M3 实现）

## 🔑 关键创新

### 维度 1：开发者体验

**从手写完整 GLSL**→**只写业务逻辑**

```cpp
// [旧方式] FixedMaterialDef
constexpr const char FULL_VS[] = R"(
    #version 450
    layout(set=0, binding=0) uniform CameraInfo { mat4 VP; } cam;
    layout(set=0, binding=1) uniform LocalToWorld { mat4 L2W; } obj;
    in vec3 Position;
    in vec3 Normal;
    out VS_Output { vec4 ClipPos; vec3 WorldPos; vec3 WorldNorm; } vso;
    mat3 GetNormalMatrix() { return transpose(inverse(mat3(obj.L2W))); }
    void main() {
        vec4 world_pos = obj.L2W * vec4(Position, 1.0);
        gl_Position = cam.VP * world_pos;
        vso.ClipPos = gl_Position;
        vso.WorldPos = world_pos.xyz;
        vso.WorldNorm = normalize(GetNormalMatrix() * Normal);
    }
)";

// [新方式] ComposedMaterialDef
constexpr const char BASIC_LIT_VS_BUSINESS[] = R"(
    vec4 VertexShaderBusiness(const VertexInput vi) {
        return vec4(vi.Position, 1.0);  // 只关心业务逻辑！
    }
)";
// 框架自动生成坐标变换、法线矩阵、输出结构体...
```

### 维度 2：可维护性

**坐标系/光照改动影响范围从 N 个材质 → 1 个框架方法**

例：若相机改为右手坐标系，仅需修改 `GenGetLocalToWorld()` 一处，所有 100+ 材质自动适配。

### 维度 3：性能

**零运行时成本**：所有辅助函数都是 inline，编译后的 SPV 与手写 GLSL 完全相同。

## 📊 代码生成示例

### BasicLit 顶点着色器生成流程

```
输入：ComposedMaterialDef BASIC_LIT_COMPOSED {
    .vertex_entries = [Position, Normal, TexCoord],
    .descriptor_entries = [ViewportInfo, CameraInfo, LocalToWorld, LightData, ...],
    .vertex_business = "vec4 VertexShaderBusiness(...) { ... }",
    .output_mode = SingleRTAlphaBlend,
}

↓ ComposeVertexShader(BASIC_LIT_COMPOSED, key)

生成的 GLSL：
  Step 1: 版本声明 + permutation #define
  Step 2: layout 声明（UBO LocalToWorld、CameraInfo 等）
  Step 3: struct VertexInput { vec3 Position; vec3 Normal; vec2 TexCoord; };
         struct VS_Output { vec4 ClipPos; vec3 WorldPosition; vec3 WorldNormal; vec2 TexCoord; uint MIId; };
         struct LightingOutput { vec3 diffuse; vec3 specular; vec3 reflection; };
  Step 4: 坐标变换基础函数（GetLocalToWorldPos, GetClipSpacePos, ...）
  Step 5: 辅助函数库（★ 关键 ★）：
         - mat4 GetLocalToWorld() { return LocalToWorld; }
         - mat3 GetNormalMatrix() { return mat3(GetLocalToWorld()); }
         - vec3 GetNormal() / GetNormal(vec3 local_norm)
         - vec4 GetPosition3D() / GetClipPosition()
         - MaterialInstance GetMaterialInstance()
  Step 6: 业务代码（开发者代码）
  Step 7: void main() { /* 调用业务代码 + 写入 VS_Output */ }

输出：~800 行完整、可编译的 GLSL vertex shader
```

### 辅助函数库自动生成（M0.5 核心）

| 场景 | 生成逻辑 | output |
|------|---------|--------|
| VS 需要 Normal | `HasVertexAttribute(def, "Normal")` → 生成 `GetNormal(vec3 local_normal)` | ✅ |
| FS 需要 Normal | 改为返回 `Input.WorldNormal`（插值） | ✅ |
| GS 需要 Position | 生成 带 `vertex_index` 参数的版本 | ✅（设计完），实现留 M2-M3 |
| 无 Position | `GenGetPositionFunctions()` 直接返回空 | ✅ |
