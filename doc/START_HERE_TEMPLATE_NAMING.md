## 🎓 命名规则一句话版

```
Value* = 按值存储（平凡类型，高效）
Ptr*   = 指针存储（用户自己管理）
Managed* = 指针存储（容器自动管理）

*Array = 动态数组
*Set   = 有序集合
*Map   = 键值对映射
```
