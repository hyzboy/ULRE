## 💡 核心建议一览

### **立即改进：HashMap 命名**

```cpp
// 改名映射

// 值存储版本
HashMapTemplate<K,V,KVData>  →  ValueHashMap<K,V,KVData>
HashMap<K,V>                 →  ValueHashMap<K,V>

// 托管版本  
ObjectHashMapTemplate<K,V,KVData> →  ManagedHashMap<K,V,KVData>
ObjectHashMap<K,V>                →  ManagedHashMap<K,V>
```

**为什么改**：
- ✅ 统一前缀规则（Value/Managed）
- ✅ 避免 Object 模糊前缀
- ✅ 与 ValueArray/ManagedArray 保持一致
- ✅ 为未来扩展奠定基础

**预期成本**：2-2.5 小时，风险低

## 🎓 学到的规则

### **命名规则完整总结**

```
前缀规则
├─ Value*    : 按值存储（平凡类型）
├─ Ptr*      : 指针存储（用户管理）
├─ Managed*  : 指针存储（自动管理）
├─ Indexed*  : 索引访问
└─ Ordered*  : 有序去重

后缀规则
├─ *Buffer   : 基础缓冲区
├─ *Array    : 动态数组
├─ *Set      : 有序集合
├─ *Map      : 键值对映射
├─ *List     : 列表
├─ *Pool     : 对象池
└─ *Registry : 注册表
```
